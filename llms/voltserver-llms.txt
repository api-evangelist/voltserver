# VoltServer

> VoltServer, Inc. invented and manufactures Digital Electricity — a Class 4 fault-managed power
> distribution technology that transmits kilowatt-scale power as digitally analyzed energy packets
> over Class 2/Class 4 cabling. VoltServer's product is hardware (transmitters and receivers), not
> software. As of a 2026-09-04 probe VoltServer publishes **no public API, no developer portal, no
> machine-readable specification (OpenAPI / AsyncAPI / GraphQL SDL / Postman collection), no SDK, no
> webhooks and no MCP server**. This file is generated by API Evangelist from the company's own public
> site; it is not published by VoltServer.

## What VoltServer sells

- [Products overview](https://voltserver.com/products/): Digital Electricity transmitters and receivers.
- [Digital Electricity transmitters](https://voltserver.com/transmitters/): TXAC family (e.g. TXAC-600-12K).
- [Digital Electricity receivers](https://voltserver.com/digital-electricity/products/digital-electricity-receivers/): RXDC, RXAC and TETRA families.
- [Class 4 power](https://voltserver.com/class-4-power/): the NEC Article 726 / UL 1400-1 regulatory context for fault-managed power.
- [Industries](https://voltserver.com/digital-electricity/industries/): service-provider networks, data centers, smart buildings and campuses, industrial and manufacturing, building electrification, transportation networks.

## Software VoltServer publishes

VoltServer ships two downloadable end-user utilities. Both are installed binaries for a technician's
laptop. Neither exposes a documented network API, and no API reference is published for either.

- [Software downloads](https://voltserver.com/support/software/)
  - VoltServer Site Tech App v2.6.0 (Windows 10/11, MSI and standalone ZIP) — released 2023-06-07.
  - VoltServer Discovery Tool v1.7.0 (macOS, DMG) — released 2023-06-01.
- [Software Terms of Use](https://voltserver.com/legal/terms-of-use/)

## Public code

- [github.com/VoltServer](https://github.com/VoltServer) — 18 public repositories. Fifteen are forks of
  third-party embedded and tooling projects (u-boot, atsamd, mdnsd, node-snmpjs, mib.js, enocean,
  exodriver, cpputest, sidekiq-batch, react-toggle, nlf, OLINUXINO, chip-ioboard, chaste_template_project,
  cypress-testrail-greenwich, agd-debian-systemd). Three are VoltServer-authored:
  - `UL1400-1_analyzer` — non-authoritative waveform analysis tools for UL 1400-1 compliance consideration.
  - `uboot-bootcount` — read/reset the u-boot bootcount register on ARM platforms.
  - `u-boot` — u-boot with patches for the Olimex AM3352-SOM.
  None of these is a client library for a VoltServer service, and none is published to npm, PyPI,
  RubyGems, crates.io, NuGet, Maven Central or pkg.go.dev.
